# Feature: Analytics (`src/features/analytics`)

## Responsibilities
- Post-event executive reporting and attendance conversion funnels.
- Revenue trends and ticket tier sales velocity.
- Demographics charts (universities, departments, student batches).
- Exportable CSV, Excel, and PDF board presentations.

## Target Supabase Interactions
- Tables: `analytics_daily_rollups`, `event_metrics`.
- Views: Materialized views aggregating attendance rates and ticket revenues.
